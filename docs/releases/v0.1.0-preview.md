# RepoRamp v0.1.0 Preview

This document describes the shape of the first public `RepoRamp` release.

It is not a promise of feature completeness. It is a snapshot of what the
project is trying to deliver in its first useful version.

## Suggested GitHub Release Title

`RepoRamp v0.1.0-preview`

## Suggested Release Summary

First public preview of `RepoRamp`, a local-first CLI for understanding
unfamiliar Python repositories.

This preview focuses on contributor onboarding and maintainer workflows:

- deterministic repository summaries
- key-file discovery
- readme and docs discovery for faster project onboarding
- structured `summary`, `files`, and `ask` JSON output
- fixture-backed tests for several Python repository shapes
- lightweight documentation for evaluators and contributors

## Release Intent

`RepoRamp` v0.1.0 is meant to be a useful early release for:

- maintainers reviewing unfamiliar Python repositories
- contributors onboarding into a new project
- developers triaging structure before making edits

The release is considered successful if it helps users answer the first few
orientation questions faster and more consistently from the command line.

## What This Release Includes

- a local-first Typer CLI
- a top-level `--version` flag
- deterministic summary output
- key-file listing
- constrained repository-orientation Q&A
- readme and documentation discovery
- JSON output for `summary`, `files`, and `ask`
- fixture-backed tests for several Python repository shapes

## Quick Install And Smoke Test

```bash
pip install -e ".[dev]"
reporamp --version
reporamp summary tests/fixtures/basic_cli
```

## Example Supported Questions

- Where is the config?
- Where are the docs?
- Where is the README?
- Where are the tests?
- Which files should I read first?
- What is the likely entry point?
- What is the package layout?
- How does this project start?

## What This Release Does Not Try To Be

`RepoRamp` v0.1.0 does not try to be:

- a code generator
- a free-form chat assistant
- a multi-language analyzer
- a hosted platform

## Quality Bar For The First Release

Before calling this first release complete, the project should continue to show:

- stable CLI behavior on fixture repositories
- deterministic output suitable for docs and demos
- transparent heuristics that contributors can understand
- a repository small enough for outside contributors to navigate quickly

## Release Notes For Evaluators

If you are looking at the project for the first time, the best quick reads are:

1. `README.md`
2. `examples/demo-session.md`
3. `docs/architecture.md`
4. `docs/roadmap.md`

Together they show what the project does now, what the output looks like, and
where the project is headed next.
