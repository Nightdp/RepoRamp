# Code of Conduct

## Our Standard

`RepoRamp` aims to be a small, practical, contributor-friendly open source
project.

We want discussions, reviews, and collaboration around this repository to be:

- respectful
- direct but constructive
- welcoming to newer contributors
- focused on the technical problem at hand

## Expected Behavior

Examples of positive behavior include:

- giving actionable, specific feedback
- assuming good intent while still being honest about problems
- helping contributors understand project scope and tradeoffs
- keeping pull requests, issues, and review comments focused and clear

## Unacceptable Behavior

Examples of unacceptable behavior include:

- harassment, personal attacks, or insulting language
- dismissive or hostile responses to basic questions
- deliberately derailing technical discussions
- publishing private or sensitive information without permission
- repeated bad-faith issue or pull request behavior

## Scope

This Code of Conduct applies within this repository's issues, pull requests,
and discussion spaces tied to project collaboration.

## Reporting

If you experience or witness unacceptable behavior, contact the maintainer at
`pding9012@gmail.com`.

Please include enough context for the report to be reviewed fairly.

## Enforcement

The maintainer may remove, edit, or reject comments, issues, or pull requests
that violate this Code of Conduct, and may restrict participation when needed
to keep the project collaborative and safe.
