# Security Policy

## Supported Versions

`RepoRamp` is still early-stage, so security fixes are only expected for the
latest development state of the project.

| Version | Supported |
| --- | --- |
| `0.1.x` | Yes |
| Older pre-release snapshots | No |

## Reporting a Vulnerability

Please do **not** open a public GitHub issue for suspected security problems.

Instead, report them privately to:

- `pding9012@gmail.com`

If possible, include:

- a short description of the issue
- affected files or commands
- reproduction steps
- potential impact
- any suggested mitigation

## Response Expectations

Best-effort targets for this repository:

- acknowledgment within 7 days
- follow-up after initial triage when the report is reproducible
- a fix or mitigation plan shared when one is available

Because this is a small maintained open source project, response times are
best-effort rather than guaranteed.
